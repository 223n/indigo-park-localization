# 翻訳の指針

Indigo Park（Chapter 1）を日本語にするときの決まりです。
機械翻訳の直訳にならないよう、先にキャラクターの人物像と口調を決めておきます。

## 作品の雰囲気

明るいテーマパークの案内と、そこに滲む不穏さの二層でできています。

案内役のランブリーは終始ハイテンションですが、話が進むと綻びが出ます。
訳文でもこの落差を残します。
明るい場面は感嘆符を多めに、崩れる場面は言いよどみと句点の省略で表します。

原文には大文字の強調が多くあります。
日本語ではカタカナ化や傍点ではなく、**語順の工夫と感嘆符**で強調します。
やりすぎると読みにくくなるため、1文に1箇所までにします。

## 登場人物

### ランブリー・ザ・ラクーン（Rambley the Raccoon）

パークの案内AIです。
台詞の大半を占めます。

| 項目 | 決めごと |
| ---- | ---- |
| 一人称 | ボク |
| 二人称 | キミ（`buddy`の訳） |
| 口調 | 明るく早口。遊園地の館内放送と、馴れ馴れしい友達口調の混在 |
| 語尾 | `〜だよ！` `〜さ！` `〜しよう！` 。断定は避けず言い切る |
| 特徴 | 自分の名前をよく出す。「キミの相棒ランブリー」のような三人称の自称も使う |

営業文句のときは丁寧語に寄せ、普段の会話はくだけた口調にします。
この切り替えが、AIらしさと不気味さを出します。

```text
Hi, I'm Rambley, Rambley the Raccoon
  → やあ、ボクはランブリー。ランブリー・ザ・ラクーンだよ！

Hey buddy! Come over here!
  → ねえキミ！ こっちこっち！

I can see in your facial tracking that you're scared- CONFUSED— angry-y-y upset-…
  → キミの顔認識データによると、怖がって——混乱して——怒って、いや、動揺し——
```

`buddy`は毎回「キミ」にせず、文脈で「ねえ」「そこのキミ」などに散らします。
同じ言葉が続くと機械翻訳に見えるためです。

### モリー・マコー（Mollie Macaw）

コンゴウインコのパイロットです。
Chapter 1では脅威にもなります。

| 項目 | 決めごと |
| ---- | ---- |
| 一人称 | アタシ |
| 口調 | 気風のいい飛行機乗り。威勢がよく、多少がさつ |
| 語尾 | `〜さ！` `〜だろ？` `〜してな！` |

```text
I'm not crashin', Rambley! I'm barnstormin'!
  → 墜落じゃないよランブリー！ アタシのは曲芸飛行さ！
```

追われる場面の彼女は台詞ではなく、聞いた言葉の反復です。
原文の反復性を保ち、訳しすぎないようにします。

### ロイドフォード・L・ライオン（Lloydford L. Lion）

自称「名優」のライオンです。
`Lloyd`の呼び名を嫌います。

| 項目 | 決めごと |
| ---- | ---- |
| 一人称 | ワタクシ |
| 口調 | 芝居がかった大仰な言い回し。尊大 |
| 語尾 | `〜であるッ！` `〜なのだ！` |
| 特徴 | 巻き舌。原文の`PRRRRROUD`のような伸ばしを再現する |

巻き舌は、カタカナの長音と小書き文字で表します。

```text
Do not SHAME me with that COMMON FOLK Name!
  → そのような下賤な呼び名でワタクシを辱めるでないッ！

I am the PRRRRROUD, the PRRRRESTIGIOUS, the PRRRRRRROFESSIONAL
  → ワタクシこそ誇り高きィィィ、由緒正しきィィィ、真に professional なるゥゥゥ
```

英単語をそのまま残すのは1箇所までにします。

### フィンリー（Finley）

引っ込み思案なシーサーペントです。

| 項目 | 決めごと |
| ---- | ---- |
| 一人称 | ぼく |
| 口調 | 小声。自信がない。ひらがなを多めに |
| 語尾 | `〜だよ…` `〜なんだ…` 。三点リーダで終えることが多い |
| 特徴 | `long`（長い・切望）の言葉遊びがある |

```text
hi rambley…
  → やあ、ランブリー…

I’m ALWAYS Long because I’m always LONGING for a new Seashell
  → ぼくがいつも長いのは、新しい貝がらをいつも長らく待ちわびてるから…
```

原文が小文字だけの行は、ひらがな主体にして声の小ささを出します。

### パーシー・プードル（Percy Poodle）

直接の台詞はありません。
ランブリーが見下して話題にします。

### 着ぐるみの録音（Jackson / Old Sport）

過去の従業員2名の雑談です。
唯一、マスコットではない生身の人間の声です。

| 項目 | 決めごと |
| ---- | ---- |
| 一人称 | オレ |
| 口調 | 投げやりで粗い。愚痴 |
| 語尾 | `〜だぜ` `〜かよ` `〜しようぜ` |

```text
Man, screw this place. I say we get our asses out of here and go straight to Vegas.
  → あーもう、こんなとこやってらんねえ。とっととバックレてベガスにでも行こうぜ。
```

明るいマスコットの声との落差が演出なので、遠慮せず崩します。

## 固有名詞

原則としてカタカナにします。
ロゴや看板として画面に出るものは原語のままにします。

アトラクション名と道具の名前は、**初めて出てくる場面だけ**原語を併記します。

```text
Well, look at that! You’re at Jetstream Junction!
  → おっと、見てごらん！ ジェットストリーム・ジャンクション（Jetstream Junction）だ！
```

2回目からはカタカナだけにします。
1行が短いときや、併記すると字幕からあふれるときは省きます。

| 原語 | 訳 | 備考 |
| ---- | ---- | ---- |
| Indigo Park | インディゴパーク | 看板の`INFORMATION`などは原語のまま |
| Rambley the Raccoon | ランブリー・ザ・ラクーン | 短くは「ランブリー」 |
| Mollie Macaw | モリー・マコー | 短くは「モリー」 |

## UIの表記

| 種類 | 決めごと |
| ---- | ---- |
| ボタン | 体言止め。「適用」「戻る」「設定を初期化」 |
| 設定の項目名 | 体言止め。「明るさ」「字幕」「カメラの遅延効果」 |
| 設定の説明文 | ですます調 |
| 操作の指示 | 「Eキーで復活」のように簡潔に。英字キーは半角 |
| 見出し | 原文が大文字でも、日本語は通常の表記にする |

数値や単位はそのまま残します。
`Default Value: English`のような既定値の記載は「初期値: English」の形にします。

## 技術的な決まり

### タグを壊さない

リッチテキストのタグはそのまま残します。
囲む範囲は日本語として自然な位置に移してかまいません。

```text
Set the language that <h>all text</> will be displayed in throughout the Game.
  → ゲーム内の<h>すべての文章</>を表示する言語を選びます。
```

### 改行を保つ

原文の`\r\n`は、訳文でも同じ数だけ入れます。
画面の折り返し位置が設計されているためです。

### 分割された台詞

音声の字幕は、1つの台詞が複数の項目に分かれています。
`data/corpus.json`の`order`が音声内の順番です。

前後をつなげて読んで、自然な流れになるよう訳します。
1項目だけを見て訳すと、文がねじれます。

```text
order 0: Nothing beats the taste of fresh Rambleberry Juice drunk
order 1: directly out of my plastic, lifeless head!
  → 0: 採れたてランブルベリージュースを飲むなら、やっぱり
  → 1: ボクのプラスチック製の、命なき頭から直接に限るね！
```

### 訳さないもの

`data/corpus.json`の`translate`が`false`の項目は訳しません。
内部の列挙やコンソールコマンド、開発中の仮置き文言です。

## 品質の目安

- 声に出して読んで、キャラクターの姿が浮かぶか
- 直前直後の行とつながるか
- 同じ英単語を機械的に同じ日本語に置き換えていないか
- 画面に収まる長さか。日本語は英語より長くなりやすい
